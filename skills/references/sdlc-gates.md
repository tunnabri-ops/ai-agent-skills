# SDLC Phase Gates

| Phase | Entry | Required outputs | Exit gate |
|---|---|---|---|
| Discovery | Problem statement | Brief, stakeholders, scope, assumptions | Problem and success criteria understood |
| Requirements | Discovery notes | Functional/NFR requirements, acceptance criteria | Critical ambiguity resolved |
| Research | Requirements baseline | Evidence log, feasibility, alternatives | Support/compatibility risks understood |
| Architecture | Research findings | Architecture, ADRs, data/API contracts | Boundaries and trade-offs reviewed |
| Foundation | Approved plan | Repo setup, CI, standards, local setup | Clean build/test path works |
| Implementation | Ready tasks | Feature code, tests, updated docs | Slice meets acceptance criteria |
| QA | Implemented feature set | Test report, defect list | Required checks pass or risks accepted |
| Review | Candidate diff | Review findings and remediation | No unresolved release-blocking issue |
| Release | Approved candidate | Deployment and rollback plan | Deployment verified |
| Handover | Released/complete work | Runbooks, README, handover | Maintainer can operate the system |
| Maintenance | Production feedback | Prioritized improvement backlog | Risks tracked and ownership assigned |
